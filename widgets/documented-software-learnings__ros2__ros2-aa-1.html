01

Position control

The control logic moves the actuator from its current position to a desired one. While it moves, it can also guarantee that a certain trajectory, passing through some specific intermediate configurations, is followed. Example: a motor drives a link of a robotic arm and must reach 90°, starting stopped at 0°. The error variable is the target minus the current position. It goes into the control system, which calculates the command that makes the motor reach the target and the error reach zero.

Why it never switches off. At zero error the control system is not stopped. It keeps running to reject external disturbances, such as gravity pushing the arm downward, and holds the motor at the desired position. Reach the target, press the gravity button, and watch it get corrected. Then untick the checkbox and repeat. Gravity always pulls the arm down toward the horizontal, so for a target above 90° it pulls the other way than for a target below 90°.

The example: the 0°, 30°, 60°, 90° positions and the 90°, 60°, 30°, 0° errors. Real controllers use many formulas for the command, so the demo uses the simplest rule: turn by the error, up to the motor's turn per iteration.

02

Velocity control

This is the control type used to drive the robot wheels in this project. The goal changes: the wheel should not reach a position but rotate at a constant speed. The input is the desired speed, and the error variable is the desired speed minus the current speed of the motor. The controller computes the command that minimizes it.

03

Force / torque control

Useful in manipulation, where fragile objects must be grasped without breaking them. Position control could press too hard and break the object, or too softly and drop it. With force control the input is the desired force, and the error is the desired force minus the force the end effector applies now. The gripper closes with the right tension.

Position control
Says: "close the gripper to position 76". It never feels what it is holding, so it works for one object size only. Too far and it crushes, too short and it drops.
Force control
Says: "squeeze until the force is 40". It measures the force, so every object size ends with the same gentle grip. That is why it suits fragile objects.

Think of a blind hand that only knows how far to close, against a hand with a sense of touch. Try the same objects in both modes, or switch on Auto grab and watch the tally at the bottom of the lab.
