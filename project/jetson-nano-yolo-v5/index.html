Jetson Nano: YOLOv5 Setup

This project documents the complete setup of YOLOv5 object detection with GPU acceleration on the Jetson Nano, including Python 3.8 environment creation, CUDA + cuDNN configuration, installation of Jetson-compatible PyTorch & Torchvision, and camera testing. This repository is part of my Jetson learning journey where I documented everything, what worked and what didn’t, while setting up YOLOv5 on Jetson Nano.

Background / Purpose

When I started working with Jetson Nano, there was no single step-by-step guide that just works.
Most tutorials online were incomplete or outdated, so I decided to:

✅ Try every possible combination
✅ Solve every error manually
✅ Document it in this repository

This repo turned into a full installation guide that others can follow without struggling.

What This Guide Covers

  • Updating Jetson Nano and installing correct JetPack version
  • Configuring CUDA and cuDNN
  • Installing Python 3.8 and fixing pip conflicts
  • Creating a virtual environment
  • Installing Jetson-compatible PyTorch + Torchvision wheels
  • Enabling additional Swap memory so YOLOv5 can train/run smoothly
  • Running YOLOv5 with:
    • Webcam / CSI camera feed
    • USB camera feed
    • Images + video feed

How it Works

  • Jetson Nano is set up with JetPack (NVIDIA drivers, CUDA, cuDNN)
  • Python 3.8 virtual environment created (isolated environment)
  • Torch + Torchvision .whl files installed (Jetson-compatible builds)
  • YOLOv5 repo cloned → dependencies installed
  • YOLOv5 executed using:
    • Static images
    • Live camera feed
