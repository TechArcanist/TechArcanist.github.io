Inspace ISRO Rocket Avionics PCB

The InSpace ISRO Rocket Avionics PCB is a compact and reliable avionics system designed for our rocket Trishul, responsible for telemetry, navigation, data logging, and event control during flight.

Features

  • Dual-Controller Architecture
    • Raspberry Pi Pico 2 (primary flight computer) + Arduino Nano 33 BLE Rev Sense 2 (secondary controller)
  • Dual Telemetry Links
    • XBee S3B Pro (RF telemetry)
    • Quectel EC200U CN (4G communication for backup location)
  • Multi-Sensor Suite
    • BNO085 (IMU), BMP390 (barometer), INA219 (power monitoring), MAX31856 (thermocouple), DS3231 (RTC)
  • NavIC GPS Integration
    • Uses India’s satellite positioning system for accurate rocket tracking
  • Data Logging
    • SD card module for black-box recording
  • Event / Pyro Control
    • MOSFET-based firing circuits for separation & parachute deployment
