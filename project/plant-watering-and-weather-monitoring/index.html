My First Project (Plant & Weather Monitoring System v1)

This was my first IoT project, where I integrated various sensors with an ESP32 microcontroller to build an IoT-powered system. It is designed to monitor soil and weather conditions while automating irrigation. The system ensures that plants receive the optimal amount of water based on real-time environmental data.

Features

  • Resistive Soil Moisture Sensors: Monitor soil moisture levels for efficient watering
  • DHT11 Sensor: Tracks temperature and humidity around plants
  • Rain Sensor: Detects rainfall to prevent overwatering
  • LCD Display: Provides real-time data visualization
  • Automated Watering: Waters plants based on sensor readings
  • Water Tank Level Monitoring: Ensures the system knows available water supply
  • Remote Monitoring & Control: Accessible through Blynk IoT app

Components Used

  • ESP32 (Microcontroller)
  • Resistive Soil Moisture Sensors
  • DHT11 Sensor (Temperature and Humidity)
  • Rain Sensor
  • LCD Display
  • Water Pump
  • Single Relay Module
  • Jumper Wires
  • Power Supply
  • Buzzer
  • Ultrasonic Sensor

How it Works

The ESP32 acts as the brain of the system, continuously gathering data from soil moisture, temperature, humidity, rain, and water tank level sensors. Based on these readings:

  • If soil moisture falls below the set threshold and no rainfall is detected, the ESP32 automatically activates the water pump through socket.
  • Sensor readings and pump activity are displayed on the LCD screen for real-time feedback.
  • Remote monitoring and control are possible via the Blynk IoT app, giving users flexibility to supervise and adjust the system from anywhere.
