Features

  • Raspberry Pi Pico 2 + Arduino Nano BLE 33 Rev2 on the same PCB (BLE33 used for backup sensor data)
  • LoRa + XBee + SIM module (multiple telemetry channels)
    • SIM module used to send location via SMS
  • Barometer-based altitude logging (BMP390)
  • IMU-based orientation & stabilization (BNO085)
  • Gas sensing (MQ4 and MQ135)
  • GPS module (NavIC Bharat chipset) for accurate positioning
  • SD card module for black box logging (keeps data safe even if telemetry is lost)
  • Servo + BLDC motor connectors (used for gyro-based actuation)
  • INA219 for power monitoring
  • RTC (DS3231) for timestamping flight logs
