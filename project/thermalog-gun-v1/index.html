ThermaLog Gun v1

The ThermaLog Gun is an IoT-powered contactless body temperature monitoring and data logging device. Built using the NodeMCU ESP8266 microcontroller and an infrared temperature sensor, this smart thermometer captures accurate body temperature readings and automatically uploads the data to Google Sheets for real-time tracking and analysis.

Features

  • Contactless Body Temperature Measurement: Uses an infrared sensor (MLX90614) to take safe, hygienic, and accurate temperature readings without physical contact.
  • Automated Data Logging: Automatically uploads every reading to Google Sheets for instant data storage and visualization.
  • Real-Time Updates: Displays live temperature readings and continuously updates the online database.
  • Portable & Wireless: Powered by an ESP8266 with built-in Wi-Fi connectivity; can run via USB or battery.
  • User-Friendly Interface: Data is easily accessible through Google Sheets, no separate app or dashboard required.

Components Used

  • ESP8266 (Microcontroller)
  • MLX90614, Contactless Infrared Temperature Sensor
  • Google Sheets API (for IoT data integration and online logging)
  • Jumper Wires (for connections between components)
  • Power Supply (USB cable or battery pack)
  • Buzzer
  • Push Button
  • OLED

How it Works

  • The MLX90614 infrared sensor measures a person’s body temperature without physical contact.
  • The ESP8266 collects these temperature readings and sends them via Wi-Fi to a Google Spreadsheet using the Google Sheets API.
  • Each reading is automatically timestamped and stored, enabling users to analyze trends and temperature variations over time.

Working

The prototype was first tested on a breadboard to validate contactless temperature measurement and cloud data logging.

The final version was assembled into a handheld thermometer gun, offering automatic data logging and remote monitoring through Google Sheets, and even sending email alerts whenever a temperature reading exceeds a set threshold.
