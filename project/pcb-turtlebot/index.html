Project Overview

The objective of this PCB was to create a compact and modular control system that works as a Raspberry Pi HAT, allowing seamless integration between the Raspberry Pi, motor drivers, sensors, and power modules required for the Turtle Bot.

Instead of using multiple separate modules with messy wiring, this PCB simplifies the entire setup by bringing all essential connections onto a single board.

Hardware Architecture

The PCB supports the following components:

ComponentFunction
Raspberry PiMain processing unit for running robot logic, navigation, and higher-level tasks
ESP32 / Arduino NanoOptional microcontroller support for low-level control tasks
Cytron Motor DriverControls DC motors used for robot movement
BNO055 IMU SensorProvides orientation and motion sensing
Level ConverterHandles communication between different voltage levels
Buck ConverterRegulates battery voltage for stable power supply
Battery InputPowers the entire robot system
JST ConnectorsProvides clean and reliable external connections
CapacitorsEnsures power stability and noise filtering

Key Feature

One of the major features of this PCB is its flexibility in microcontroller selection.
Users can choose between:

- ESP32
- Arduino Nano

depending on their project requirements.

They simply need to:

- Attach the PCB HAT to the Raspberry Pi
- Connect either an ESP32 or Arduino Nano
- Connect motors
- Connect battery supply
Attach sensors and supporting modules

This makes the system modular and easy to maintain.

PCB Design Goal

The main goal behind this design was to:

  • Reduce complex wiring
  • Create a cleaner robotics hardware setup
  • Improve modularity
  • Make hardware integration easier
  • Enable quick replacement of modules
