Privacy policy

This is a personal portfolio. It has no accounts, no sign-ups, no ads and no tracking. This page explains the little that does happen when you visit, and how I use YouTube.

Last updated 8 November 2026

Who runs this site

techarcanist.com is the personal portfolio of Lavitra Sahu (Tech Arcanist), Kanpur, India. Contact: lavitra@techarcanist.com.

What this site collects

  • No personal data is collected by this site. There are no forms, accounts, comments, analytics or advertising trackers.
  • Your theme choice (blue or green) is saved in your own browser's local storage so the site remembers it. It never leaves your device.
  • If you email me, I receive your email address and message and use them only to reply.

Services this site relies on

  • Hosting: the site is served by GitHub Pages. Like any web host, GitHub may log technical data such as your IP address for security and operations. See the GitHub Privacy Statement.
  • Fonts: some fonts load from Google Fonts. See the Google Privacy Policy.
  • Videos: many project videos are YouTube videos embedded with YouTube's privacy-enhanced mode (youtube-nocookie.com). YouTube does not set tracking cookies until you press play; once you play a video, YouTube's own terms and privacy policy apply.

YouTube API Services

I use a private tool, run only by me, that uploads my own project and tutorial videos to my own YouTube channel through the YouTube API Services, so they can be embedded on this site.

  • The tool is used only by the site owner. Visitors never sign in with Google here, and no visitor data is sent to or received from YouTube by this site.
  • The only data handled is my own: the video files, titles and descriptions I choose to upload, and the sign-in token for my own channel, which is stored only on my own computer and is never shared.
  • By watching an embedded video you are also bound by the YouTube Terms of Service, and YouTube's handling of data is described in the Google Privacy Policy.
  • Access granted to the tool can be revoked at any time from Google security settings (third-party access). Revoking it deletes the tool's access immediately; the stored token is then useless and is deleted from my computer.

Your choices

  • You can clear the saved theme at any time by clearing this site's data in your browser.
  • For any question, or to ask me to delete an email you sent, write to lavitra@techarcanist.com.

Changes

If this policy changes, the new version will be published on this page with a new date.
