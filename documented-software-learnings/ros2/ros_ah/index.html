Translation Vector Between Two Turtles: Python

Introduction

In the previous chapter, we used Turtlesim to explore ROS 2 nodes, topics, services, velocity commands, and the pose of a turtle in a 2D environment.

Now we will apply what we have learned about translation vectors.

We will create a Python ROS 2 node that subscribes to the pose of two turtles and calculates the translation vector from turtle1 to turtle2.

The goal is to determine how far the second turtle is from the first turtle along the X and Y axes.

By the end of this chapter, we will have a node that continuously calculates the translation vector and displays its values in the terminal.

Open Turtlesim

First, we need to start the Turtlesim simulator.

Open a terminal and run:

ros2 run turtlesim turtlesim_node

Place your terminal screenshot here.

The Turtlesim window will open with the default turtle, named turtle1.

Spawn Another Turtle

To calculate the translation vector between two turtles, we first need two turtles in the same environment.

We can create another turtle using the ROS 2 /spawn service.

Run and press tab twice and it will autocomplete

ros2 service call /spawn turtlesim/srv/Spawn "
ros2 service call /spawn turtlesim/srv/Spawn "x: 1.0
y: 4.0
theta: 0.0
name: 'turtle2'"

After the service call succeeds, you should see turtle2 at approximately the coordinates (1, 4).

List the Available Topics

Now that we have two turtles, let’s inspect the topics available in ROS 2.

Open another terminal and run:

ros2 topic list

You should see topics associated with both turtles, including:

/turtle1/cmd_vel
/turtle1/color_sensor
/turtle1/pose
/turtle2/cmd_vel
/turtle2/color_sensor
/turtle2/pose

The /turtle1/pose topic contains information about the first turtle’s position and orientation in the Turtlesim world.

Similarly, /turtle2/pose contains the pose of the second turtle.

now lets create ros2 nodes to calculate translation vector betwen turtle 1 and turtle 2

Create the Python ROS 2 Node

Now we will create a Python node that automatically performs this calculation.

Open VS Code.

Inside the bumperbot_py_examples package, create the Python file at:

bumperbot_py_examples/
└── bumperbot_py_examples/
    └── simple_turtlesim_kinematics.py
simple_turtlesim_kinematics.py

Write the Python Code

Open simple_turtlesim_kinematics.py and add:

import rclpy
from rclpy.node import Node
from turtlesim.msg import Pose


class SimpleTurtlesimKinematics(Node):
    
    def __init__(self):
        super().__init__("simple_turtlesim_kinematics")
        self.turtle1_pose_sub_ = self.create_subscription(Pose, "/turtle1/pose", self.turtle1PoseCallback, 10) 
        self.turtle2_pose_sub_ = self.create_subscription(Pose, "/turtle2/pose", self.turtle2PoseCallback, 10)

        self.last_turtle1_pose_ = Pose()
        self.last_turtle2_pose_ = Pose()

    
    def turtle1PoseCallback(self, msg):
        self.last_turtle1_pose_ = msg


    def turtle2PoseCallback(self, msg):
        self.last_turtle2_pose_ = msg

        Tx = self.last_turtle2_pose_.x - self.last_turtle1_pose_.x
        Ty = self.last_turtle2_pose_.y - self.last_turtle1_pose_.y


        self.get_logger().info("""\n
                      Translation Vector turtle1 -> turtle2\n
                      Tx: %f\n
                      Ty: %f\n""" % (Tx,Ty))
        

def main():
    rclpy.init()
    simple_turtlesim_kinematics = SimpleTurtlesimKinematics()
    rclpy.spin(simple_turtlesim_kinematics)
    simple_turtlesim_kinematics.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()

Add the Entry Point to setup.py

Open setup.py inside the bumperbot_py_examples package.

Inside the existing console_scripts list, add:

'simple_turtlesim_kinematics = bumperbot_py_examples.simple_turtlesim_kinematics:main'

Add the Dependency to package.xml

Open:

bumperbot_py_examples/package.xml

Add:

<exec_depend>turtlesim</exec_depend>

Build the Workspace

After changing the Python package, we need to build the workspace.

Open a terminal and run:

cd bumperbot_ws
colcon build

Wait for the build to finish successfully.

Run the Translation Vector Node

Open a new terminal.

Go to the workspace if necessary and source it and run:

. install/setup.bash
ros2 run bumperbot_py_examples simple_turtlesim_kinematics

This starts the node that calculates the translation vector between the two turtles.

You should see output similar to:

[simple_turtlesim_kinematics]:

Translation Vector turtle1 -> turtle2

Tx: -4.544445
Ty: -1.544445

The numbers shown here are examples from your run. They depend on the actual positions of the turtles.

What do the negative values mean?

For these values:

Tx: -4.544445
Ty: -1.544445

Turtle 2 is to the left of Turtle 1 and below it in the world coordinate system.

The node keeps running and calculating the translation vector as new pose messages arrive.

Move Turtle 1 and Observe the Change

Now let's see whether our calculation responds to changes in the turtle positions.

Open another terminal.

Run the keyboard teleoperation node:

ros2 run turtlesim turtle_teleop_key

Make sure the teleoperation terminal is focused, then move Turtle 1 using the keyboard.

As Turtle 1 moves, the translation vector printed by simple_turtlesim_kinematics changes.

For example:

Before movement:

Tx: -4.544445
Ty: -1.544445

After moving Turtle 1, the values may become:

Tx: -3.200000
Ty: -0.800000

These second values are illustrative; your actual results depend on how you move the turtle.
