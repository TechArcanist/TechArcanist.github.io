Rotation Matrix Between Two Turtles: Python

Introduction

In the previous chapter, we created a Python ROS 2 node that calculates the translation vector between two turtles in Turtlesim.

Now, we will extend that node to calculate the relative orientation and rotation matrix between the two turtles.

Each turtle has its own position and orientation in the Turtlesim world. By subscribing to both turtles’ pose topics, we can calculate how their orientations differ.

We will continue using the simple_turtlesim_kinematics.py node created in the previous chapter.

Start the Turtlesim Simulator

First, we need to start the Turtlesim simulator.

Open a terminal and run:

ros2 run turtlesim turtlesim_node

The Turtlesim window will open with the default turtle, named turtle1.

Spawn Another Turtle

To calculate the translation vector between two turtles, we first need two turtles in the same environment.

We can create another turtle using the ROS 2 /spawn service.

Run and press tab twice and it will autocomplete

ros2 service call /spawn turtlesim/srv/Spawn "
ros2 service call /spawn turtlesim/srv/Spawn "x: 1.0
y: 4.0
theta: 0.0
name: 'turtle2'"

After the service call succeeds, you should see turtle2 at approximately the coordinates (1, 4).

List the Available Topics

Now that we have two turtles, let’s inspect the topics available in ROS 2.

Open another terminal and run:

ros2 topic list

You should see topics associated with both turtles, including:

/turtle1/cmd_vel
/turtle1/color_sensor
/turtle1/pose
/turtle2/cmd_vel
/turtle2/color_sensor
/turtle2/pose

Rotation Matrix

Complete Python Code

Replace the existing code with the following updated version:

import rclpy
from rclpy.node import Node
from turtlesim.msg import Pose
import math


class SimpleTurtlesimKinematics(Node):
    
    def __init__(self):
        super().__init__("simple_turtlesim_kinematics")
        self.turtle1_pose_sub_ = self.create_subscription(Pose, "/turtle1/pose", self.turtle1PoseCallback, 10) 
        self.turtle2_pose_sub_ = self.create_subscription(Pose, "/turtle2/pose", self.turtle2PoseCallback, 10)

        self.last_turtle1_pose_ = Pose()
        self.last_turtle2_pose_ = Pose()

    
    def turtle1PoseCallback(self, pose):
        self.last_turtle1_pose_ = pose


    def turtle2PoseCallback(self, pose):
        self.last_turtle2_pose_ = pose
        Tx = self.last_turtle2_pose_.x - self.last_turtle1_pose_.x
        Ty = self.last_turtle2_pose_.y - self.last_turtle1_pose_.y
        theta_rad = self.last_turtle2_pose_.theta - self.last_turtle1_pose_.theta
        theta_deg = 180 * theta_rad / 3.14
        self.get_logger().info("""\n
                      Translation Vector turtle1 -> turtle2\n
                      Tx: %f\n
                      Ty: %f\n
                      Rotation Matrix turtle1 -> turtle2\n 
                      theta (rad): %f\n
                      theta (deg): %f\n
                      |R11   R12|:  |%f %f|\n
                      |R21   R22|   |%f %f|\n""" %
                      (
                        Tx, Ty, theta_rad, theta_deg,
                        math.cos(theta_rad), -math.sin(theta_rad),
                        math.sin(theta_rad), math.cos(theta_rad)
                      )
                    )
        

def main():
    rclpy.init()

    simple_turtlesim_kinematics = SimpleTurtlesimKinematics()
    rclpy.spin(simple_turtlesim_kinematics)
    
    simple_turtlesim_kinematics.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()

Rotate a Turtle and Observe the Change

Now, let's see how the rotation matrix changes when a turtle rotates.

Open another terminal.

Run the keyboard teleoperation node:

ros2 run turtlesim turtle_teleop_key

Make sure the teleoperation terminal is focused, then move Turtle using the keyboard.

As the relative orientation changes, the following values will change:

  • Relative angle in radians.
  • Relative angle in degrees.
  • The four rotation-matrix elements.

For example, your output may show:

Translation Vector turtle1 -> turtle2

Tx: -4.544445
Ty: -1.544445

Rotation Matrix turtle1 -> turtle2

theta (rad): 0.772815
theta (deg): 44.301479
|R11  R12|: |0.715948  -0.698153|
|R21  R22|: |0.698153   0.715948|
