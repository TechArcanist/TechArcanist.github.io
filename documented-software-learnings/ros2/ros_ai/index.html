Translation Vector Between Two Turtles: CPP

NOTE: I will be prioritizing Python and temporarily pausing C++ implementations after this chapter. You can explore the C++ chapters covered so far. I will first complete the remaining topics in Python, then revisit the skipped chapters to add their corresponding C++ implementations.

Introduction

In the previous chapter, we used Turtlesim to explore ROS 2 nodes, topics, services, velocity commands, and the pose of a turtle in a 2D environment.

Now, we will apply our understanding of translation vectors by developing a C++ ROS 2 node.

The node will subscribe to the pose of two turtles, calculate the translation vector from turtle1 to turtle2, and display the result in the terminal.

Start the Turtlesim Simulator

First, we need to start the Turtlesim simulator.

Open a terminal and run:

ros2 run turtlesim turtlesim_node

The Turtlesim window will open with the default turtle, named turtle1.

Spawn Another Turtle

To calculate the translation vector between two turtles, we first need two turtles in the same environment.

We can create another turtle using the ROS 2 /spawn service.

Run and press tab twice and it will autocomplete

ros2 service call /spawn turtlesim/srv/Spawn "
ros2 service call /spawn turtlesim/srv/Spawn "x: 1.0
y: 4.0
theta: 0.0
name: 'turtle2'"

After the service call succeeds, you should see turtle2 at approximately the coordinates (1, 4).

List the Available Topics

Now that we have two turtles, let’s inspect the topics available in ROS 2.

Open another terminal and run:

ros2 topic list

You should see topics associated with both turtles, including:

/turtle1/cmd_vel
/turtle1/color_sensor
/turtle1/pose
/turtle2/cmd_vel
/turtle2/color_sensor
/turtle2/pose

The /turtle1/pose topic contains information about the first turtle’s position and orientation in the Turtlesim world.

Similarly, /turtle2/pose contains the pose of the second turtle.

now lets create ros2 nodes to calculate translation vector between turtle 1 and turtle 2

Create the C++ ROS 2 Node

Now, we will create a ROS 2 node named simple_turtlesim_kinematics.

The node will subscribe to both pose topics, save the latest pose information, and calculate the translation vector.

We will divide the implementation into two files:

  • A header file (.hpp) to declare the class, functions, and variables.
  • A source file (.cpp) to define the functions and implement the node’s behavior.

Open your bumperbot_cpp_examples package in Visual Studio Code.

Create the following file structure:

simple_turtlesim_kinematics.hpp
simple_turtlesim_kinematics.cp

Declare the Class in the Header File

Open:

simple_turtlesim_kinematics.hpp

Add the following code:

#ifndef SIMPLE_TURTLESIM_KINEMATICS_HPP
#define SIMPLE_TURTLESIM_KINEMATICS_HPP

#include <rclcpp/rclcpp.hpp>
#include <turtlesim/msg/pose.hpp>

class SimpleTurtlesimKinematics : public rclcpp::Node
{
public:
    SimpleTurtlesimKinematics(const std::string& name);

    void turtle1PoseCallback(const turtlesim::msg::Pose& pose);

    void turtle2PoseCallback(const turtlesim::msg::Pose& pose);

private:
    rclcpp::Subscription<turtlesim::msg::Pose>::SharedPtr turtle1_pose_sub_;
    rclcpp::Subscription<turtlesim::msg::Pose>::SharedPtr turtle2_pose_sub_;

    turtlesim::msg::Pose last_turtle1_pose_;
    turtlesim::msg::Pose last_turtle2_pose_;
};

#endif // SIMPLE_TURTLESIM_KINEMATICS_HPP

Implement the C++ Node

Open:

src/simple_turtlesim_kinematics.cpp

Add the following code:

#include "bumperbot_cpp_examples/include/simple_turtlesim_kinematics.hpp"
using std::placeholders::_1;


SimpleTurtlesimKinematics::SimpleTurtlesimKinematics(const std::string& name)
    : Node(name)
{
    turtle1_pose_sub_ = create_subscription<turtlesim::msg::Pose>(
        "/turtle1/pose", 10, std::bind(&SimpleTurtlesimKinematics::turtle1PoseCallback, this, _1));

    turtle2_pose_sub_ = create_subscription<turtlesim::msg::Pose>(
        "/turtle2/pose", 10, std::bind(&SimpleTurtlesimKinematics::turtle2PoseCallback, this, _1));
}


void SimpleTurtlesimKinematics::turtle1PoseCallback(const turtlesim::msg::Pose& pose)
{
    last_turtle1_pose_ = pose;
}


void SimpleTurtlesimKinematics::turtle2PoseCallback(const turtlesim::msg::Pose& pose)
{
    last_turtle2_pose_ = pose;
    float Tx = last_turtle2_pose_.x - last_turtle1_pose_.x;
    float Ty = last_turtle2_pose_.y - last_turtle1_pose_.y;
    RCLCPP_INFO_STREAM(get_logger(), "\nTranslation Vector turtle1 -> turtle2 \n" <<
                    "Tx: " << Tx << "\n" <<
                    "Ty: " << Ty << "\n");
}


int main(int argc, char* argv[])
{
  rclcpp::init(argc, argv);
  auto node = std::make_shared<SimpleTurtlesimKinematics>("simple_turtlesim_kinematics");
  rclcpp::spin(node);
  rclcpp::shutdown();
  return 0;
}

in CMake Lists

Add:

find_package(turtlesim REQUIRED)






include_directories(include)






add_executable(simple_turtlesim_kinematics src/simple_turtlesim_kinematics.cpp)
ament_target_dependencies(simple_turtlesim_kinematics rclcpp turtlesim)
install(
  DIRECTORY include
  DESTINATION include
)
install(TARGETS
  simple_publisher
  simple_subscriber
  simple_parameter
  simple_turtlesim_kinematics
  DESTINATION lib/${PROJECT_NAME}
)

Add the Dependency to package.xml

Add:

<exec_depend>turtlesim</exec_depend>

Build the Workspace

Open a terminal and run:

cd bumperbot_ws
colcon build

Wait for the build to finish successfully.

Run the Translation Vector Node

Open a new terminal.

Go to the workspace if necessary and source it and run:

. install/setup.bash
ros2 run bumperbot_cpp_examples simple_turtlesim_kinematics

This starts the node that calculates the translation vector between the two turtles.

You should see output similar to:

[simple_turtlesim_kinematics]:

Translation Vector turtle1 -> turtle2

Tx: -4.544445
Ty: -1.544445

What do the negative values mean?

For these values:

Tx: -4.544445
Ty: -1.544445

Turtle 2 is to the left of Turtle 1 and below it in the world coordinate system.

The node keeps running and calculating the translation vector as new pose messages arrive.

Move Turtle 1 and Observe the Change

Now let's see whether our calculation responds to changes in the turtle positions.

Open another terminal.

Run the keyboard teleoperation node:

ros2 run turtlesim turtle_teleop_key

Make sure the teleoperation terminal is focused, then move Turtle 1 using the keyboard.

As Turtle 1 moves, the translation vector printed by simple_turtlesim_kinematics changes.

For example:

Before movement:

Tx: -4.544445
Ty: -1.544445

After moving Turtle 1, the values may become:

Tx: -3.200000
Ty: -0.800000

These second values are illustrative; your actual results depend on how you move the turtle.
