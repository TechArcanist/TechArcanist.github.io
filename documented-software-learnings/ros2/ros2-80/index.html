IMU Republisher

Introduction

Chapter 79 explained the extended Kalman filter, and the next chapters use a ready-made one from the robot_localization package to improve the linear and the angular velocity of the robot with the wheel encoders and the IMU (chapter 79, linearization and the EKF loop). Before that filter can be set up, the IMU messages need one small change.

This chapter writes a tiny node, imu_republisher.py. It receives every IMU message on imu/out, changes only the frame ID in its header to base_footprint_ekf, and publishes it again on a new topic, imu_ekf. The readings themselves are not touched. This is trivial, but it is needed for the configuration of robot_localization.

What must already work

  • The package bumperbot_localization with kalman_filter.py builds (chapter 77).
  • The simulated IMU publishes on imu/out (chapter 75).

Writing the node

Create the file

In VS Code, open src, then bumperbot_localization, then the bumperbot_localization folder inside it. Next to kalman_filter.py, create a new file called imu_republisher.py.

The code

The whole file, 26 lines:

#!/usr/bin/env python3
import rclpy
import time
from rclpy.node import Node
from sensor_msgs.msg import Imu

imu_pub = None

def imuCallback(imu):
    global imu_pub
    imu.header.frame_id = "base_footprint_ekf"
    imu_pub.publish(imu)


def main(args=None):
    global imu_pub
    rclpy.init(args=args)
    node = Node('imu_republisher_node')
    time.sleep(1)
    imu_pub = node.create_publisher(Imu, "imu_ekf", 10)
    imu_sub = node.create_subscription(Imu, "imu/out", imuCallback, 10)
    rclpy.spin(node)
    rclpy.shutdown()

if __name__ == '__main__':
    main()

What each part does

LinesWhat happens
1 to 5The shebang (needed because CMake installs the file as a program) and the imports: rclpy, time for the pause, Node, and the Imu message from sensor_msgs.
7A global variable for the publisher, empty (None) for now. There is no class in this file, so a global lets main fill it and the callback use it.
9 to 12The callback. For every IMU message it writes base_footprint_ekf into header.frame_id and publishes the same message again. Everything else (stamp, orientation, angular velocity, acceleration) stays as received.
15 to 17main starts and ROS 2 is initialised. global imu_pub on line 16 is needed because line 20 assigns the global.
18A plain Node named imu_republisher_node.
19A 1 second pause, so the IMU is already publishing and robot_localization has started before the node begins its work.
20, 21The publisher on the new topic imu_ekf and the subscription on imu/out that calls imuCallback; queue size 10 for both.
22, 23, 25, 26spin keeps the node running until Ctrl+C, then shutdown; the guard starts main when the file is run as a program.

Line 10 (global imu_pub inside the callback) is optional: the callback only reads imu_pub, and Python finds a global name for reading without it. Line 16 is not optional: without it, line 20 would make a new local variable in main, the global would stay None, and the first IMU message would crash the node with AttributeError: 'NoneType' object has no attribute 'publish'.

The new frame name is the same as the child frame that the noisy odometry message carries, base_footprint_ekf (chapter 69). As far as I know, the frame the IMU sends before the change is the frame of its own link, imu_link.

Install and build

CMakeLists.txt

Open CMakeLists.txt of bumperbot_localization. In install(PROGRAMS ...), where kalman_filter.py is already installed, add the new file below it:

install(PROGRAMS
  ${PROJECT_NAME}/kalman_filter.py
  ${PROJECT_NAME}/imu_republisher.py
  DESTINATION lib/${PROJECT_NAME}
)

The node uses only rclpy and sensor_msgs, which the package already depends on (chapter 77), so package.xml does not change.

Build the workspace

Go to the workspace:

cd bumperbot_ws

Build it, to check that everything compiles and the new file is installed:

colcon build

Remember

  • imu_republisher.py receives every IMU message on imu/out, sets header.frame_id to base_footprint_ekf, and publishes it again on imu_ekf. The readings do not change.
  • It is needed for the configuration of robot_localization and its extended Kalman filter.
  • Without a class, a global variable holds the publisher. global is needed in main (which assigns it), not in the callback (which only reads it).
  • A 1 second pause at start-up lets the IMU and robot_localization start first.
  • Install the file with install(PROGRAMS ...) in CMakeLists.txt; no new dependency, so package.xml stays the same. Then colcon build.
