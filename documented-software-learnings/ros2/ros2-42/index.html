Simple Speed Controller: Python

Introduction

In the previous chapters, we learned about ROS 2 Control and how to move the BumperBot using velocity commands.

Now, we will develop a Python ROS 2 node that converts the robot’s velocity commands into individual wheel velocity commands.

The robot receives two main velocity components:

  • Linear velocity (v): Controls how fast the robot moves forward or backward.
  • Angular velocity (ω): Controls how fast the robot rotates.

Our node will use the robot’s wheel radius and wheel separation to calculate the required velocity for each wheel.

The calculated wheel velocities will then be published to the simple_velocity_controller/commands topic, which is used by the ROS 2 Control velocity controller.

Create the Python Package Structure

First, open your bumperbot_controller package in Visual Studio Code.

Create the Python Package Folder

Inside the bumperbot_controller package, create another folder with the same name:

bumperbot_controller

Create the Python Files

Inside this folder, create two Python files:

  1. __init__.py
  2. simple_controller.py

The __init__.py file can remain empty. It marks the directory as a Python package.

__init__.py
simple_controller.py

Create the Simple Controller Node

Open:

bumperbot_controller/simple_controller.py

Add the following code.

Python Code

#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from std_msgs.msg import Float64MultiArray
from geometry_msgs.msg import TwistStamped
import numpy as np


class SimpleController(Node):

    def __init__(self):
        super().__init__("simple_controller")
        self.declare_parameter("wheel_radius", 0.033)
        self.declare_parameter("wheel_separation", 0.17)

        self.wheel_radius_ = self.get_parameter("wheel_radius").get_parameter_value().double_value
        self.wheel_separation_ = self.get_parameter("wheel_separation").get_parameter_value().double_value

        self.get_logger().info("Using wheel radius %d" % self.wheel_radius_)
        self.get_logger().info("Using wheel separation %d" % self.wheel_separation_)

        self.wheel_cmd_pub_ = self.create_publisher(Float64MultiArray, "simple_velocity_controller/commands", 10)
        self.vel_sub_ = self.create_subscription(TwistStamped, "bumperbot_controller/cmd_vel", self.velCallback, 10)

        self.speed_conversion_ = np.array([[self.wheel_radius_/2, self.wheel_radius_/2],
                                           [self.wheel_radius_/self.wheel_separation_, -self.wheel_radius_/self.wheel_separation_]])
        self.get_logger().info("The conversion matrix is %s" % self.speed_conversion_)


    def velCallback(self, msg):
        robot_speed = np.array([[msg.twist.linear.x],
                                [msg.twist.angular.z]])
        wheel_speed = np.matmul(np.linalg.inv(self.speed_conversion_), robot_speed) 

        wheel_speed_msg = Float64MultiArray()
        wheel_speed_msg.data = [wheel_speed[1, 0], wheel_speed[0, 0]]

        self.wheel_cmd_pub_.publish(wheel_speed_msg)


def main():
    rclpy.init()

    simple_controller = SimpleController()
    rclpy.spin(simple_controller)
    
    simple_controller.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()

Configure CMakeLists.txt

Our package uses ament_cmake as its build type.

However, we are also adding Python code to this package. Therefore, we need to configure CMake so that it can install the Python package and its executable script.

Open the CMakeLists.txt file inside bumperbot_controller.

Use the following configuration, preserving any additional targets or installation rules already required by your package.

Complete CMakeLists.txt

cmake_minimum_required(VERSION 3.8)
project(bumperbot_controller)

if(CMAKE_COMPILER_IS_GNUCXX OR CMAKE_CXX_COMPILER_ID MATCHES "Clang")
  add_compile_options(-Wall -Wextra -Wpedantic)
endif()


find_package(ament_cmake REQUIRED)
find_package(ament_cmake_python REQUIRED)
find_package(rclpy REQUIRED)
find_package(geometry_msgs REQUIRED)
find_package(std_msgs REQUIRED)

ament_python_install_package(${PROJECT_NAME})

install(
  DIRECTORY config launch
  DESTINATION share/${PROJECT_NAME}
)

install(PROGRAMS
  ${PROJECT_NAME}/simple_controller.py
  DESTINATION lib/${PROJECT_NAME}
)

if(BUILD_TESTING)
  find_package(ament_lint_auto REQUIRED)
  set(ament_cmake_copyright_FOUND TRUE)
  set(ament_cmake_cpplint_FOUND TRUE)
  ament_lint_auto_find_test_dependencies()
endif()

ament_package()

Update package.xml

After modifying CMakeLists.txt, we also need to declare the dependencies in package.xml.

Open the package.xml file inside bumperbot_controller.

Package Configuration

  </export>
</package>

Build the Workspace

We have now completed the Python controller and configured the package.

Let's build the workspace to check whether everything is configured correctly.

Open a terminal and navigate to the workspace:

cd bumperbot_ws

Run the following command:

colcon build

Wait for the build to complete successfully.
