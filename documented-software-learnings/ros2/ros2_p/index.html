Rviz

So far, we have created a URDF/Xacro description of our robot. But a robot description is only useful if we can actually see and inspect what it represents. This is where RViz2 becomes extremely useful.

RViz2 is one of the most important visualization tools in ROS 2. It allows us to visualize information being published through ROS 2 topics in a graphical and intuitive way.
