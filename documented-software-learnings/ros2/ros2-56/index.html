Euler to Quaternion: Turning the Robot with tf_transformations


Introduction

In the previous chapters the node simple_tf_kinematics published a moving transform, odom → bumperbot_base, that only drove forward. Its rotation was always x 0, y 0, z 0, w 1: no turn.

This chapter makes the base turn as well. People think about turns in angles (roll, pitch, yaw), but ROS 2 stores every rotation as a quaternion, four numbers x, y, z, w. The library tf_transformations converts between the two and does the quaternion maths:

  • quaternion_from_euler(roll, pitch, yaw) turns three angles (in radians) into a quaternion.
  • quaternion_multiply(a, b) combines two turns into one.
  • quaternion_inverse(q) gives the opposite turn.

The node starts with no turn, multiplies in a small yaw of 0.05 radians on every tick, and after 100 ticks switches to the inverse so the base turns back. In RViz the base frame drives along X while turning back and forth.

The node from the TF2 listener chapter must already build and run. This chapter changes that file and adds one dependency.

Write the code

Open simple_tf_kinematics.py in bumperbot_py_examples/bumperbot_py_examples.

Make it look like this. Everything from the listener chapter stays; the new parts are marked below.

import rclpy
from rclpy.node import Node
from bumperbot_msgs.srv import GetTransform
from tf2_ros.static_transform_broadcaster import StaticTransformBroadcaster
from tf2_ros import TransformBroadcaster, TransformException
from tf2_ros.buffer import Buffer
from tf2_ros.transform_listener import TransformListener
from geometry_msgs.msg import TransformStamped
from tf_transformations import quaternion_from_euler, quaternion_multiply, quaternion_inverse

class SimpleTfKinematics(Node):

    def __init__(self):
        super().__init__("simple_tf_kinematics")
        self.x_increment_ = 0.05
        self.last_x_ = 0.0
        self.rotations_counter_ = 0

        # TF Broadcaster
        self.static_tf_broadcaster_ = StaticTransformBroadcaster(self)
        self.dynamic_tf_broadcaster_ = TransformBroadcaster(self)
        self.static_transform_stamped_ = TransformStamped()
        self.dynamic_transform_stamped_ = TransformStamped()

        # TF Listener
        self.tf_buffer_ = Buffer()
        self.tf_listener_ = TransformListener(self.tf_buffer_, self)

        self.static_transform_stamped_.header.stamp = self.get_clock().now().to_msg()
        self.static_transform_stamped_.header.frame_id = "bumperbot_base"
        self.static_transform_stamped_.child_frame_id = "bumperbot_top"
        self.static_transform_stamped_.transform.translation.x = 0.0
        self.static_transform_stamped_.transform.translation.y = 0.0
        self.static_transform_stamped_.transform.translation.z = 0.3
        self.static_transform_stamped_.transform.rotation.x = 0.0
        self.static_transform_stamped_.transform.rotation.y = 0.0
        self.static_transform_stamped_.transform.rotation.z = 0.0
        self.static_transform_stamped_.transform.rotation.w = 1.0

        self.static_tf_broadcaster_.sendTransform(self.static_transform_stamped_)
        self.get_logger().info("Publishing static transform between %s and %s" %
                      (
                        self.static_transform_stamped_.header.frame_id,
                        self.static_transform_stamped_.child_frame_id
                      ))

        # Timer
        self.timer_ = self.create_timer(0.1, self.timerCallback)

        # Service Server
        self.get_transform_srv_ = self.create_service(GetTransform, "get_transform", self.getTransformCallback)

        # Quaternion
        self.last_orientation_ = quaternion_from_euler(0, 0, 0)
        self.orientation_increment_ = quaternion_from_euler(0, 0, 0.05)

    def timerCallback(self):
        self.dynamic_transform_stamped_.header.stamp = self.get_clock().now().to_msg()
        self.dynamic_transform_stamped_.header.frame_id = "odom"
        self.dynamic_transform_stamped_.child_frame_id = "bumperbot_base"
        self.dynamic_transform_stamped_.transform.translation.x = self.last_x_ + self.x_increment_
        self.dynamic_transform_stamped_.transform.translation.y = 0.0
        self.dynamic_transform_stamped_.transform.translation.z = 0.0
        # self.dynamic_transform_stamped_.transform.rotation.x = 0.0
        # self.dynamic_transform_stamped_.transform.rotation.y = 0.0
        # self.dynamic_transform_stamped_.transform.rotation.z = 0.0
        # self.dynamic_transform_stamped_.transform.rotation.w = 1.0

        # Euler to Quaternion
        q = quaternion_multiply(self.last_orientation_, self.orientation_increment_)
        self.dynamic_transform_stamped_.transform.rotation.x = q[0]
        self.dynamic_transform_stamped_.transform.rotation.y = q[1]
        self.dynamic_transform_stamped_.transform.rotation.z = q[2]
        self.dynamic_transform_stamped_.transform.rotation.w = q[3]

        self.dynamic_tf_broadcaster_.sendTransform(self.dynamic_transform_stamped_)
        self.last_x_ = self.dynamic_transform_stamped_.transform.translation.x
        self.last_orientation_ = q
        self.rotations_counter_ += 1
        if self.rotations_counter_ >= 100:
            self.orientation_increment_ = quaternion_inverse(self.orientation_increment_)
            self.rotations_counter_ = 0

    def getTransformCallback(self, req, res):
        self.get_logger().info("Requested Transform between %s and %s" % (req.frame_id, req.child_frame_id))
        requested_transform = TransformStamped()
        try:
            requested_transform = self.tf_buffer_.lookup_transform(req.frame_id, req.child_frame_id, rclpy.time.Time())
        except TransformException as e:
            self.get_logger().error("An error occurred while transforming %s and %s: %s" %
                         (req.frame_id, req.child_frame_id, e))
            res.success = False
            return res

        res.transform = requested_transform
        res.success = True
        return res

def main():
    rclpy.init()

    simple_tf_kinematics = SimpleTfKinematics()
    rclpy.spin(simple_tf_kinematics)

    simple_tf_kinematics.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()

What is new

  • Line 9 imports the three quaternion tools from tf_transformations. In this library a quaternion is a list in the order x, y, z, w, the same order as the rotation fields of a ROS 2 message.
  • Line 17 adds rotations_counter_, which counts the ticks since the turning direction last changed.
  • Lines 54 and 55 make two quaternions in __init__: last_orientation_ starts as no turn, [0, 0, 0, 1], and orientation_increment_ is a yaw of 0.05 radians (about 2.9°), which is [0, 0, 0.024997, 0.999688].
  • Lines 64 to 67, the old fixed rotation, are now comments.
  • Line 70: on every tick, q = quaternion_multiply(last_orientation_, orientation_increment_) adds one more small turn. Turns are combined by multiplying quaternions, never by adding the numbers.
  • Lines 71 to 74 copy q[0], q[1], q[2], q[3] into x, y, z, w. Python counts from 0, so q[3] is w.
  • Line 78 keeps q for the next tick. Lines 79 to 82 count the ticks; at 100 (10 seconds, 5 radians of turning) the increment is replaced by its inverse and the counter starts again, so the base turns back.

One yaw, four numbers

A turn around Z only changes z and w: z = sin(yaw ÷ 2) and w = cos(yaw ÷ 2). Turn the robot and multiply in single ticks:

Add the dependency

Open package.xml of bumperbot_py_examples (in the same package as the node) and add this line next to the other dependencies:

<exec_depend>tf_transformations</exec_depend>

The line tells ROS 2 that the package needs tf_transformations when it runs. It does not install the library. If the node later stops with ModuleNotFoundError: No module named 'tf_transformations', install it. As far as I know, on ROS 2 Jazzy this is:

sudo apt install ros-jazzy-tf-transformations

Use the name of your ROS 2 distribution instead of jazzy if it is different. As far as I know the library also needs the Python package transforms3d; if an error names it, install that too.

Build, run and test

Build

Go to the workspace and build:

cd ~/bumperbot_ws
colcon build

What you should see

Starting >>> bumperbot_msgs
...
Finished <<< bumperbot_py_examples [3.84s]

Summary: 5 packages finished [5.76s]

Terminal 2: RViz

Open another terminal, go to the workspace, source it and start RViz:

cd ~/bumperbot_ws
. install/setup.bash
rviz2

In RViz set Fixed Frame to odom, then click Add and choose TF.

Terminal 3: run the node

Open a third terminal, source the workspace and run the node:

cd ~/bumperbot_ws
. install/setup.bash
ros2 run bumperbot_py_examples simple_tf_kinematics

What you should see

[INFO] [simple_tf_kinematics]: Publishing static transform between bumperbot_base and bumperbot_top

In RViz the frame bumperbot_base (with bumperbot_top above it) drives along odom X at 0.5 m per second and turns 0.05 radians every tick. After 10 seconds it turns back, and after 20 seconds it faces forward again.

Look closely: the base keeps moving along odom X even while it faces another way, so it slides sideways. That is how this example is written, because the step x + 0.05 on line 61 is always along odom X.

To see the four numbers change, open one more sourced terminal:

ros2 topic echo /tf

What you should see (roughly, about 10 times a second)

transforms:
- header: ... frame_id: odom
  child_frame_id: bumperbot_base
  transform:
    translation: {x: ..., y: 0.0, z: 0.0}
    rotation: {x: 0.0, y: 0.0, z: ..., w: ...}

Remember

  • ROS 2 stores every rotation as a quaternion x, y, z, w. No turn is [0, 0, 0, 1].
  • quaternion_from_euler(roll, pitch, yaw) takes radians: 0.05 rad is about 2.9°, and 5 would be about 286°.
  • Turns are combined by multiplying quaternions (quaternion_multiply), never by adding the numbers.
  • The inverse flips the signs of x, y and z. Flipping all four signs gives the same turn, not the opposite.
  • Keep the new orientation for the next tick, or the turn never builds up.
  • Declare the library with <exec_depend>tf_transformations</exec_depend>, and install it if Python cannot find it.
