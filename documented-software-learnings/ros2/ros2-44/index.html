Teleoperating the BumperBot with a Joystick

Introduction

In the previous chapters, we developed a Python Simple Controller and used it to move the BumperBot in the Gazebo simulation by publishing velocity commands manually.

Now, we will make robot control easier by connecting a physical joystick to our system.

We will use two ROS 2 packages:

  • joy: Reads input from the physical joystick and publishes joystick data.
  • joy_teleop: Converts joystick inputs into robot velocity commands.

The joystick will control the BumperBot through our existing Python Simple Controller.

Create the Joystick Teleoperation Launch File

Open the bumperbot_controller package in Visual Studio Code.

Navigate to the launch folder and create a new Python file named:

joystick_teleop.launch.py
bumperbot_controller/
│
├── launch/
│   ├── controller.launch.py
│   └── joystick_teleop.launch.py

Note: Keep the launch file inside the launch folder and the YAML configuration files inside config. This matches the package installation structure used in our earlier chapter.

Write the Code

import os

from ament_index_python.packages import get_package_share_directory

from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node


def generate_launch_description():


    joy_teleop = Node(
        package="joy_teleop",
        executable="joy_teleop",
        parameters=[os.path.join(get_package_share_directory("bumperbot_controller"), "config", "joy_teleop.yaml")]
    )

    joy_node = Node(
        package="joy",
        executable="joy_node",
        name="joystick",
        parameters=[os.path.join(get_package_share_directory("bumperbot_controller"), "config", "joy_config.yaml")]
    )

    return LaunchDescription(
        [
            joy_teleop,
            joy_node
        ]
    )

Configure the Joystick Driver

Now, we need to configure the physical joystick.

Inside the config folder, create a YAML file named:

joy_config.yaml

The recommended package structure is:

bumperbot_controller/
│
├── config/
│   ├── joy_config.yaml

Write the Code

joystick:
  ros__parameters:
    device_id: 0
    device_name: ""
    deadzone: 0.5
    autorepeat_rate: 20.0
    sticky_buttons: false
    coalesce_interval_ms: 1

Configure the Joystick Teleoperation

Name it:

joy_teleop.yaml

This file defines how the joystick input is converted into robot velocity commands.

The recommended package structure is:

bumperbot_controller/
│
├── config/
│   ├── joy_config.yaml
│   └── joy_teleop.yaml

Write the code

joy_teleop:
  ros__parameters:
    move:
      type: topic
      interface_type: geometry_msgs/msg/TwistStamped
      topic_name: bumperbot_controller/cmd_vel
      deadman_buttons: [5]
      axis_mappings:
        twist-linear-x:
          axis: 1
          scale: 1.0
          offset: 0.0
        twist-angular-z:
          axis: 3
          scale: 8.0
          offset: 0.0

Build the Workspace

cd bumperbot_ws

Run the following command:

colcon build

Wait for the build to complete successfully.

Start the Gazebo Simulation

Open another terminal and source the workspace:

. install/setup.bash

Now start the Gazebo simulation:

ros2 launch bumperbot_description gazebo.launch.py

Wait for the BumperBot to appear in Gazebo.

Launch the Python Controller

open a new terminal and Now, start the controller system.

Run:

. install/setup.bash
ros2 launch bumperbot_controller controller.launch.py

This will start:

  • The Joint State Broadcaster.
  • The Simple Velocity Controller.
  • The Python Simple Controller node.

The Python node will receive robot velocity commands, convert them into individual wheel velocities, and publish the results to the wheel controller.

Connect and Launch the Joystick

Now, connect your physical joystick to the computer.

You can use a USB connection or a supported wireless connection.

In this demonstration, we are using the HyperX Clutch Gladiate controller.

Open another terminal and source the workspace:

. install/setup.bash

Launch the joystick teleoperation system:

ros2 launch bumperbot_controller joystick_teleop.launch.py

This starts two nodes:

  1. joy_node: Reads the physical joystick input.
  2. joy_teleop: Converts joystick inputs into velocity commands.

You should see output indicating that the joystick has been detected.

Teleoperate the BumperBot

Once the joystick has been detected, you can start controlling the robot.

Using the HyperX Clutch Gladiate controller:

1 - Enable movement

Keep the configured deadman button pressed.

2 - Move forward and backward

Use the designated movement axis to move the robot forward or backward.

3 - Turn the robot

Use the designated turning axis to turn the robot left or right.

Understand the Joystick Control Architecture

The complete control process involves three main components:

1. Joy Node

The joy package reads input from the physical joystick and publishes the joystick data.

2. Joy Teleop Node

The joy_teleop package reads the joystick data and converts the configured button and axis inputs into velocity commands.

3. Python Simple Controller

Our existing Python controller receives the velocity commands, calculates the individual wheel velocities, and publishes them to the wheel controller.

Data Flow

This allows us to control the robot directly using the joystick instead of manually publishing velocity commands.
